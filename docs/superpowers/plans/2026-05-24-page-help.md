# Page Help — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exibir um ícone `?` acessível ao lado do título de cada tela admin, abrindo um tooltip com texto explicativo sobre a função da tela e seu impacto no sistema.

**Architecture:** Componente React `PageHelp` (Tooltip do shadcn/Radix, acessível via teclado) recebe a string de texto como prop. No backend, `LookupController` ganha método `description(): string` incluído no `buildConfig()`; controllers de páginas individuais passam `pageDescription` diretamente no `Inertia::render()`. Cada página React lê o prop e renderiza `<PageHelp>`.

**Tech Stack:** React 19, shadcn/ui Tooltip (Radix UI — já instalado), Lucide `CircleHelp`, Vitest + Testing Library, PHPUnit + `assertInertia`.

- [ ] **Step 3: Criar o componente**

```tsx
// resources/js/components/page-help.tsx
import { CircleHelp } from 'lucide-react';
import { Tooltip, TooltipContent, TooltipTrigger } from '@/components/ui/tooltip';

interface PageHelpProps {
  text: string;
}

export function PageHelp({ text }: PageHelpProps) {
  if (!text) return null;

  return (
    <Tooltip>
      <TooltipTrigger asChild>
        <button aria-label="Ajuda" className="text-muted-foreground hover:text-foreground transition-colors">
          <CircleHelp className="size-4" />
        </button>
      </TooltipTrigger>
      <TooltipContent className="max-w-xs text-sm">
        {text}
      </TooltipContent>
    </Tooltip>
  );
}
```

> Nota: `Tooltip` do shadcn já envolve `TooltipProvider` internamente (ver `resources/js/components/ui/tooltip.tsx` linha 20) — não é necessário adicionar `TooltipProvider` manualmente.
